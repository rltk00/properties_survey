# 실거래 지도 (용인 · 수원 · 오산)

GitHub Pages 주소로 열면 바로 쓸 수 있습니다. 설치할 것도, 켜 둘 서버도 없습니다.
검색할 때마다 브라우저가 국토부 실거래가, 경기도 버스정보, 카카오맵 API를 직접 호출합니다.

## 올리기 (GitHub Pages)

1. https://github.com/new 에서 저장소를 만듭니다.
   - 이름: `properties_survey`
   - 공개 범위: **Public**
2. 새 저장소 화면에서 **uploading an existing file**을 눌러 `index.html`을 끌어다 놓고 **Commit changes**를 누릅니다.
3. 저장소의 **Settings → Pages**로 갑니다.
   - Source: *Deploy from a branch*
   - Branch: `main` / `/ (root)`
   - **Save**를 누르고 1~2분 기다리면 주소가 나옵니다: `https://<아이디>.github.io/properties_survey/`

## 카카오 설정

https://developers.kakao.com 에 로그인한 뒤 **앱**에서 사용할 앱을 고릅니다. 앱이 없으면 새로 만듭니다.

- **카카오맵 사용 설정**을 켭니다.
- **플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인**에 `https://<아이디>.github.io`를 등록합니다. 경로(`/properties_survey`)는 빼고 넣습니다. 예전 화면에서는 이 메뉴가 "플랫폼 → Web → 사이트 도메인"이었습니다.
- 같은 화면의 **JavaScript 키**를 복사해 둡니다.

## 공공데이터포털 (data.go.kr)

아래 5개 API를 각각 활용신청합니다. 인증키는 하나를 같이 씁니다(Encoding/Decoding 중 아무거나).

- 국토교통부_아파트 매매 실거래가 자료 (`RTMSDataSvcAptTrade`)
- 국토교통부_아파트 전월세 실거래가 자료 (`RTMSDataSvcAptRent`)
- 국토교통부_오피스텔 매매 실거래가 자료 (`RTMSDataSvcOffiTrade`)
- 국토교통부_오피스텔 전월세 실거래가 자료 (`RTMSDataSvcOffiRent`)
- 경기도_정류소 조회 (`busstationservice`)

## 사용

1. Pages 주소를 열고 **API 키 설정**에 키 2개를 저장합니다. 키는 이 브라우저에만 저장되고, 저장소에는 올라가지 않습니다.
2. 지도를 움직이면 화면에 걸친 구의 실거래를 자동으로 불러옵니다. 한 번 불러온 구는 다시 부르지 않습니다.
   - 위쪽의 시·구·동을 고르면 그 위치로 지도가 이동합니다.
   - 너무 축소하면 자동 불러오기를 멈춥니다.
3. 목록과 핀에는 화면 안의 건물만 나옵니다. 유형, 거래 방식, 전용면적(㎡ 또는 평)으로 바로 걸러집니다.
4. 핀에는 최근 실거래가가 표시됩니다. 핀을 누르면 아래 내용이 나옵니다.
   - 면적별 거래 내역
   - 이지어린이집, 광교효성해링턴타워까지의 직선거리
   - 가까운 버스 정류장 3곳 (정류장을 누르면 노선)

## 무료 사용량

- 카카오맵: 하루 약 30만 회 지도 로드. 정확한 한도는 콘솔의 쿼터 화면에서 확인합니다.
- 공공데이터포털: 개발계정 기준으로 API마다 하루 1만 회 정도입니다. 한 구를 1년치 불러오면 48회를 씁니다.

## 참고

- 면적은 전용면적 기준입니다. 1평 = 3.3058㎡로 환산합니다. 전용 84㎡는 약 25.7평입니다.
- 거리는 직선거리입니다.
- 건물 위치는 브라우저에 저장해 두므로, 두 번째부터는 빠르게 불러옵니다.
